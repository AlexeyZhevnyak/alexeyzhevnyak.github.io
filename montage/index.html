montage

A command-line tool that renders a creator's videos and publishes them to that creator's own YouTube channels.

montage publishes through the YouTube Data API to YouTube channels you own. It uploads; it never reads your account. See the privacy policy and the terms of use.

What it does

montage is a personal production tool. It runs on the operator's own computer and covers the whole path from raw material to a published video:

  • renders long-form videos and vertical short-form cut-downs with ffmpeg;
  • generates instrumental background music locally, with no external service involved;
  • aligns narration to images using a speech-recognition model that runs on the same machine;
  • uploads the finished files to the operator's own YouTube channels on a schedule.

Who uses it

The operator and nobody else. montage has no accounts, no sign-up and no server. Each installation is authorised by the person who owns the YouTube channels it uploads to, and it can only upload to those channels. It is not a service offered to third parties.

How it uses the YouTube Data API

Publishing is the only part of montage that contacts YouTube. It requests a single OAuth scope, https://www.googleapis.com/auth/youtube.upload, and calls exactly two endpoints:

  • videos.insert — uploads a rendered video file;
  • thumbnails.set — attaches the cover image rendered alongside it.
montage makes no read requests. It does not list, search, fetch or analyse anything on YouTube, and it holds no permission that would let it. Both endpoints it uses write the operator's own files to the operator's own channel.

Scheduling

A release is a long video plus several short-form cut-downs. montage spaces them out instead of posting everything at once: at most three videos per channel per day, an hour apart, continuing the following day. The queue is a file on the operator's machine, and each upload is attempted once.

Privacy and terms

montage stores its Google credentials on the operator's own machine and transmits nothing to anyone but YouTube. The privacy policy sets out exactly what is accessed, used, stored and shared; the terms of use cover what you agree to by running it.
